# My Blog

Live: **https://blog.rayou.me**

A personal blog built with Next.js, featuring markdown and LaTeX support.

## Quick Start

```bash
bun install && bun dev
```

## Blog Posts

Edit or add markdown files in `content/posts/`. The frontmatter format:

```markdown
---
title: Your Post Title
date: 2026-05-15
lang: en
---
```

If you want to edit the contents, please raise pr to master, and it would be merged to run.
