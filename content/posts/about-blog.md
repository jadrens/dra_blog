## 技术栈

这个博客使用 Next.js 14 构建，结合以下技术：

- **前端框架**: Next.js 14 (App Router)
- **UI 组件**: Material-UI (MUI)
- **样式**: Tailwind CSS + CSS Variables
- **物理引擎**: Matter.js (彩纸动画)
- **Markdown 解析**: react-markdown
- **数学公式**: KaTeX
- **代码高亮**: rehype-highlight

## 功能特性

- 响应式设计，支持暗色/亮色主题切换
- 支持 LaTeX 数学公式渲染
- 代码语法高亮
- 平滑的页面过渡动画
- 主页彩纸背景互动效果
- 国际化支持 (中/英)
- 目录自动生成与锚点跳转
- 浏览量统计

## 字体

- 中文: MiSans (小米免费商用字体)
- 英文标题: Inter (粗体)
- 正文: Nunito
- 代码: JetBrains Mono
