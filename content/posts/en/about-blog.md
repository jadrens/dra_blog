## Tech Stack

This blog is built with Next.js 14, combining the following technologies:

- **Frontend Framework**: Next.js 14 (App Router)
- **UI Components**: Material-UI (MUI)
- **Styling**: Tailwind CSS + CSS Variables
- **Physics Engine**: Matter.js (confetti animation)
- **Markdown Parsing**: react-markdown
- **Math Rendering**: KaTeX
- **Code Highlighting**: rehype-highlight

## Features

- Responsive design with dark/light theme toggle
- LaTeX math formula rendering support
- Code syntax highlighting
- Smooth page transition animations
- Interactive confetti background on homepage
- Internationalization support (Chinese/English)
- Auto-generated table of contents with anchor navigation
- View count statistics

## Fonts

- Chinese: MiSans (Xiaomi free commercial font)
- English Headings: Inter (Bold)
- Body Text: Nunito
- Code: JetBrains Mono
