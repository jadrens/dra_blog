## Problem Background

With Linux 7.1+ kernel officially merging the new native NTFS driver into mainline, a historical issue was exposed in the `ntfs-3g` package in Arch Linux official repositories.

The official `PKGBUILD` hardcodes a symlink:
`ln -s /usr/bin/ntfs-3g /usr/bin/mount.ntfs`

This "hijacking" causes any standard `mount -t ntfs` call to be forcibly redirected to the user-space FUSE driver (ntfs-3g). This not only adds overhead but also prevents users of 7.1 and newer kernels from enjoying the high-performance native driver.

## Solution

To embrace the new kernel features while not breaking the experience for older kernel (like LTS) users, I submitted a Merge Request to the official repository. The core idea is to deprecate the static symlink and introduce an adaptive intelligent routing script (Wrapper).

- **Script Language**: Pure POSIX `sh` (no `bash` dependency, compliant with Arch KISS principle)
- **Core Logic**: Dynamically get `uname -r` at runtime to implement request routing
- **String Processing**: Pure Shell built-in parameter expansion (such as `${KVER%%.*}`), zero external subprocess overhead

## Features

- **Dynamic Kernel Awareness**:
  - **Kernel >= 7.1**: Route to native kernel driver (`mount -i -t ntfs "$@"`)
  - **Kernel < 7.1**: Downgrade to FUSE driver (`ntfs-3g "$@"`)
- **Bulletproof Fallback**: Strict numeric type validation. When encountering non-standard or unparseable kernel version numbers like `custom-kernel-rc`, silently intercept and safely fall back to FUSE.
- **Transparent Replacement**: The script completely takes over `/usr/bin/mount.ntfs`, completely transparent to upper-layer applications and ordinary users' mounting habits.

## Strict Two-Way Testing

Before submitting the code, I thoroughly validated the script in both environments using loop virtual devices:

- **New Driver Bypass Test**: In the `7.1.0-rc2-1-cachyos-rc` environment, successfully bypassing the FUSE daemon, `findmnt` verified FSTYPE as pure `ntfs`.
- **Old Kernel Fallback Test**: In the `7.0.3-arch1-2` environment, perfectly triggering the downgrade logic, `findmnt` verified FSTYPE as `fuseblk`.
